# 本地 AI 配置与公众号排版契约设计

## 目标

把项目收缩为本地单用户微信公众号编辑器：无需登录即可编辑和调用 AI；点击“AI 模型”直接配置多个供应商；配置只保存在本机并立即生效。同时修复 AI 把英文元分析、提示词残片或普通 Markdown 清理结果写入排版稿的问题。

## 已确认的产品边界

- 服务默认仅监听 `127.0.0.1`，不把本地免登录 API 暴露到局域网或公网。
- 删除登录页、管理员会话、退出登录和 CSRF 交互；不再要求 `ADMIN_PASSWORD_HASH` 或 `PUBLIC_ORIGIN`。
- “AI 模型”保持为顶部独立入口，打开后直接显示供应商、协议、Base URL、模型和 API Key 配置。
- 配置写入本机 `data/` 下的服务端持久化文件，保存后立即更新运行时；API Key 不回显，已配置时输入框用圆点占位，输入新值才会替换原密钥。
- 保留多供应商、多协议、模型刷新与连接测试能力。
- 浏览器通过 `file://` 打开时仍只提供基础编辑；AI 配置和调用需要运行本地 Node 服务。
- 删除与本地免登录边界冲突的公网 Nginx、Docker 部署入口；Git 历史仍可恢复。许可证、上游说明和本地运行资料继续保留。

## AI 排版模式

默认模式为“公众号改写”：理解原始内容后重组为适合公众号阅读的成稿，并选择编辑器支持的语义组件。另提供“忠实整理”：保留原文事实、措辞和章节，只改善层级与排版。

两种模式都遵循以下约束：

- 不增加原文不存在的事实、数据、案例、引语、日期、人物或结论。
- 只返回最终 Markdown，不返回分析、任务说明、道歉、系统提示词或代码围栏。
- 原始内容作为 JSON 数据字段传给模型，不使用可能被正文闭合的 `<source>` 分隔符。
- AI 只决定内容结构和语义组件，现有 renderer 负责主题色彩与 HTML；AI 不生成 CSS 或 HTML。

## 组件选择策略

- 长文或有明确主题的文章使用 `HERO`。
- 两个及以上主要章节使用 `PART`，每个主要章节前使用 `CHAPTER`。
- 有顺序的步骤使用 `FLOW`；并列能力或要点使用 `FEATURES`。
- 真实案例使用 `CASE`；关键提醒使用 `CALLOUT`。
- 收束文章时使用 `SUMMARY`，需要明确结尾时使用 `END`。
- `GALLERY`、`VOCAB`、`REFCARD`、`VIDEO` 仅在原始内容确实含相应素材时使用。
- 短文不为满足模板而强行堆叠组件。

主题 ID 在服务端转换为简短的中文主题提示，描述文章气质和组件密度；不再只把裸 ID 作为 `Preferred theme cue` 发送给模型。

## 输出验收与修复

服务端在接受模型结果前执行：

1. 清理最外层 Markdown 围栏并拒绝空结果、HTML。
2. 拒绝高置信元泄漏，如 `The user has provided`、`my own system prompt`、`Let me think`、`Preferred theme cue`、`<source>`。
3. 只允许 renderer 支持的组件名，并检查开始/结束标签是否成对、不可交叉嵌套。
4. 对长篇“公众号改写”结果要求至少出现一个结构组件；普通正文和短文不强制模板。
5. 首次失败时，将原始候选和具体错误送回同一模型做一次修复；第二次失败返回错误，不覆盖前端已有排版稿。

## 本地配置数据流

```text
点击“AI 模型”
  -> GET /api/ai/config（无需登录，API Key 不回显）
  -> PUT /api/ai/config（仅本机来源，保存加密配置）
  -> 配置仓库更新内存运行时
  -> 后续模型刷新、连接测试、AI 排版立即使用新配置
```

服务只接受 loopback 连接，并对浏览器请求校验来源仍是本机 HTTP Origin。API Key 不通过配置接口返回；圆点仅是空输入框的视觉占位符，不是真实密钥，也不写入 `localStorage`、静态 HTML、日志或错误信息。

## 错误处理

- 未启动本地服务：界面提示“请先运行 npm start”，不丢稿。
- 未配置可用模型：打开“AI 模型”并聚焦首个缺失字段。
- 保存失败或连接失败：保留表单当前输入，展示服务端安全错误，不显示上游响应体或密钥。
- AI 输出未通过契约且修复失败：保留原 Markdown，提示重新生成或切换模型。

## 验收标准

- 打开 `http://127.0.0.1:3000` 后无登录 UI、无认证请求，直接可打开 AI 配置。
- 保存配置后无需重启即可读取安全状态、测试连接并调用排版。
- GET 配置、日志、静态资源、错误信息和 `localStorage` 均不含完整 API Key；已配置状态以圆点占位和状态文案呈现。
- DeepSeek 类输出中的英文元分析会触发一次修复，不会直接写入编辑器。
- `</source>`、未知组件、未闭合组件均有自动化回归测试。
- `npm test` 全绿；桌面和移动宽度下 AI 设置弹层可操作；刷新后配置状态仍存在。

## 非目标

- 不实现公网账号体系、多用户配置隔离、云端数据库或远程密钥管理。
- 不让 AI 直接生成微信 HTML。
- 不删除 AGPL 许可证、上游归属或已有主题渲染能力。
